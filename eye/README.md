# Eye / SANS

Edit `sans.py` for TRT calculations, `interventions.py` for recorded countermeasures, and `web/learn.html` for the education/countermeasure guide. `web/index.html`, `app.js`, and `style.css` own the interface. `docs/` contains source notes.

Read `../SANS_RESEARCH_HANDOFF.md` before research or calculation changes. Run from the repository root: `python sans_web.py`, or `python -m eye.server`. The Live Server page at `eye/web/index.html` uses a read-only static bundle; the Python server supplies live data instead.
